web-translator 데모

스크립트 한 줄 임베드로 동작하는 클라이언트 사이드 웹 페이지 번역 위젯. 우측 상단 드롭다운에서 언어 선택 시 본문 텍스트 노드가 실시간 교체됨.

특징

  • API 키 불필요. 별도 서버 불필요.
  • jsDelivr CDN으로 무료 배포.
  • localStorage 캐시(TTL 7일)로 반복 요청 최소화.
  • MutationObserver로 SPA 동적 콘텐츠 자동 번역.
  • 원문 언어 재선택 시 원문 복원.

사용법

<script
  src="https://cdn.jsdelivr.net/gh/EaseHee/web-translator@1/dist/translate.min.js"
  data-langs="en,ja,zh-CN,es,fr"
  data-default="ko"
  data-position="top-right"
  data-auto="false"
  defer></script>

스타일·위치 상세 조정

위젯 외관은 두 가지 방법으로 조정 가능. 둘 다 함께 사용 가능하며 우선순위는 inline data 속성 > CSS 변수 override.

1. data-* 인라인 옵션

<script src="...translate.min.js"
  data-position="bottom-center"
  data-offset-x="24px"
  data-offset-y="20px"
  data-theme="dark"
  data-font-size="13px"
  data-radius="10px"
  data-bg="#0b1220"
  data-color="#e5e7eb"
  data-border-color="#1f2937"
  data-shadow="0 4px 12px rgba(0,0,0,.3)"
  defer></script>

지원 키: position(top-right · top-left · top-center · bottom-right · bottom-left · bottom-center), theme(auto · light · dark), offset-x, offset-y, z-index, font-family, font-size, line-height, color, bg, border-color, border-width, radius, padding-y, padding-left, padding-right, shadow, focus-color, focus-width, arrow, arrow-position, busy-opacity, transition.

여러 변수를 한 번에 지정할 때는 data-style 사용 가능. CSS 변수 선언 형식 그대로 입력.

<script src="...translate.min.js"
  data-style="--wt-radius:12px;--wt-shadow:none;--wt-padding-y:8px"
  defer></script>

2. CSS 변수 override

<style>
#wt-widget {
  --wt-offset-x: 24px;
  --wt-offset-y: 20px;
  --wt-radius: 12px;
  --wt-bg: #111;
  --wt-color: #fff;
  --wt-border-color: transparent;
  --wt-shadow: 0 6px 16px rgba(0,0,0,.4);
}
</style>
